## ローカル起動
Python 3 が入ったパソコンで、このフォルダをターミナルで開きます。

    python3 -m http.server 8000 --bind 127.0.0.1 --directory dist

Windows では python3 を py -3 に置き換えてください。
ブラウザで http://127.0.0.1:8000/ を開きます。終了はターミナルで Ctrl+C。
HTMLのダブルクリックではなくHTTPサーバーで起動してください。
ゲーム実行にChatGPTのログインや外部CDNは必要ありません。
ブラウザ・端末による描画差や音声の自動再生制限はあります。
元サイトのブラウザ内設定や進行中の対戦状態はこのZIPには含まれません。
